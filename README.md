## 👨🏻‍💻 About me

I design and ship **end-to-end ML & GenAI systems**, from data ingestion to cloud deployment.
I enjoy working where classical ML, agentic GenAI and large-scale data processing meet.

- 🤖 Building **RAG & agentic workflows** (LangGraph, MCP, tool-calling)
- ⚙️ Building & maintaining **production-grade cloud-based ETL workflows** (Spark, Polars)
- 🦀 High-performance data processing with **Rust + Polars**
- ⚡ **FastAPI is my default:** there's one behind almost every project I ship
